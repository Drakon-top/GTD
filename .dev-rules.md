# Development Rules — GTD Personal Management App

## Git Workflow

- **Ветка main/master** — стабильная, всегда собирается
- Каждая фича — отдельный коммит с осмысленным описанием
- Формат коммитов: `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`, `test:`
- Пример: `feat: add User JPA entity with BCrypt password hashing`

## Код

### Java / Spring Boot
- Java 21, Spring Boot 3.5.x
- Пакетная структура: `com.gtd.backend.{module}.{layer}`
  - Модули: `auth`, `context`, `task`, `category`, `reminder`, `sync`, `notification`
  - Слои внутри модуля: `controller`, `service`, `repository`, `model`, `dto`, `exception`
- Lombok для Entity и DTO (не для сервисов)
- Все эндпоинты под `/api/v1/`
- Валидация входных данных через Jakarta Validation (`@Valid`, `@NotBlank`, etc.)
- Soft delete через поле `is_deleted` (не физическое удаление)
- UUID для первичных ключей
- Optimistic locking через `@Version`

### SQL / Flyway
- Миграции в `src/main/resources/db/migration/`
- Формат имени: `V{N}__{description}.sql` (два подчёркивания)
- Только forward миграции, без undo
- Все FK с ON DELETE RESTRICT (если не указано иное)

### REST API
- Ресурсные URL: `/api/v1/contexts/{id}/tasks`
- HTTP-методы по назначению: GET, POST, PUT, PATCH, DELETE
- Ответы ошибок: `{ "error": "...", "message": "...", "status": 400 }`
- Пагинация: `?page=0&size=20` (Spring Pageable)
- Фильтрация через query parameters

### Тесты
- Unit-тесты для сервисов (Mockito)
- Интеграционные тесты для контроллеров (`@WebMvcTest` / `@SpringBootTest`)
- Тесты миграций (Flyway + H2 или Testcontainers)
- Имя теста: `should{Action}_when{Condition}`

## Безопасность

- JWT для аутентификации
- BCrypt для паролей
- Никаких секретов в коде — только через env переменные
- CORS настроен для конкретных доменов

## PR Checklist

- [ ] Код компилируется: `./mvnw clean package`
- [ ] Тесты проходят: `./mvnw test`
- [ ] Нет hardcoded секретов
- [ ] Flyway миграция идемпотентна
- [ ] REST эндпоинты задокументированы (SpringDoc аннотации)
- [ ] Acceptance criteria из tasks.json выполнены
